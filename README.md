# Sprint_7: API-тесты Яндекс.Самокат

Автотесты API учебного сервиса https://qa-scooter.education-services.ru (requests + pytest + Allure).

## Покрытие

- Создание курьера
- Логин курьера
- Создание заказа (параметризация по цветам)
- Список заказов
- Удаление курьера (дополнительное задание)
- Принятие заказа (дополнительное задание)

## Структура

- `api/` классы-обёртки над ручками
- `tests/` тесты (по классу на ручку) и фикстуры в `conftest.py`
- `data.py`, `urls.py`, `constants.py`, `helpers.py` данные, адреса, константы, генерация данных

## Запуск

```
pip install -r requirements.txt
python -m pytest tests/ --alluredir=target/allure-results
allure serve target/allure-results
```

## Известные особенности стенда

- Логин без поля `password` не возвращает ответ (таймаут), ожидается 400. Тест помечен `xfail`.
- Созданные тестами заказы не удаляются: рабочий формат запроса отмены заказа не определён.
